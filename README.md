# Ice Cream Sales Prediction 

This project predicts ice cream sales based on temperature using a simple machine learning model.

## Dataset

The dataset contains:

* Temperature (independent variable)
* Sales (dependent variable)

## What I Did

* Data Visualization
* Linear Regression Model
* Prediction of sales

## Tools Used

* Python
* Pandas
* Matplotlib
* Scikit-learn

## How to Run

1. Install libraries using requirements.txt
2. Run the notebook or model.py
